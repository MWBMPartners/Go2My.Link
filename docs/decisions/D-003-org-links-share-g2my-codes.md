# D-003 — Organisation links share the g2my.link codes

- **Date:** 2026-11-26
- **Issue:** #289
- **Question:** An organisation member makes a g2my.link short link but the organisation has no short web address of its own. How should it work?
- **Answer:** Their g2my.link links work like anyone else's. Each code on g2my.link is used once across everybody; the organisation still sees the link and its statistics.
- **Rules out:** Refusing to create links until an organisation sets up its own short web address.
- **Where it is implemented:** Not yet built.
- **Supersedes:** nothing
