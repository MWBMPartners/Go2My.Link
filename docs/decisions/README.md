# 🗳️ Decisions — one file each

**Search this folder before putting any question to the owner.** If a record covers it, follow it
and say so. Ask again only when a measured fact makes the recorded answer unworkable, quoting the
record and stating the fact.

**Never edit a record.** A decision taken again is a new file that names the one it replaces.
Each record gives the date, the question, the answer, what it rules out, where it is implemented and
what it replaces, and is also noted on the GitHub issue it governs.

**Older decisions** (up to 2026-09-21, numbered 1–45) are on GitHub issue **#243** and have not yet
been copied into this folder. Search both. Copying them, and adding the automatic shape check, is
tracked on its own issue.
