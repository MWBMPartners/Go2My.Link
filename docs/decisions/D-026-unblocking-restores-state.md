# D-026 — Removing a staff block restores the link as it was

- **Date:** 2026-11-28
- **Issue:** #325
- **Question:** What happens when staff remove a block from a link?
- **Answer:** The link goes back to how it was before the block; a link its owner had switched off stays off.
- **Rules out:** Switching every unblocked link on.
