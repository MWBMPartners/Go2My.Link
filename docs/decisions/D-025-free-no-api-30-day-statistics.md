# D-025 — Free has no API access and shows 30 days of statistics at launch

- **Date:** 2026-11-28
- **Issue:** #328
- **Question:** Free organisations get statistics and API access although the plan data says no. What should launch do?
- **Answer:** Block API keys on Free (creating and using them) and show only the last 30 days of statistics to Free.
- **Rules out:** Leaving statistics history and API access open on Free at launch.
- **Where it is implemented:** Not yet built.
- **Supersedes:** D-020, only in that the Free limits are now to be enforced before launch; the pricing page may describe them once they are
