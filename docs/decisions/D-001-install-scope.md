# D-001 — Install scope: essentials first

- **Date:** 2026-11-26
- **Issue:** #243
- **Question:** How much must be built before the new install?
- **Answer:** Essentials first: fix everything that is broken, unsafe, legally required for personal data, or that would stop a fresh install working.
- **Rules out:** Paid-plan admin screens, new LinksPage features and single sign-on before the install.
- **Where it is implemented:** Not code. It sets the order of the work queue (see the handoff).
- **Supersedes:** nothing
